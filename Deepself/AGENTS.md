# AGENTS.md

## 项目定位

- `Deepself` 是 `yao_1` 仓库下的独立子项目。
- 当前用于整理用户本人朋友圈中的图文、视频和转发选择，分析长期表达风格与内容偏好，并生成可复用的个人文案 Skill。

## 工作规则

- 默认使用中文沟通，称呼用户为 Sir。
- 开始开发前，先明确项目目标、输入输出、使用场景和验收标准。
- 优先选择本地、简单、可维护的方案，避免无必要的复杂架构和依赖。
- 修改范围保持在 `Deepself/` 内；如需改动仓库其他目录，先说明原因和影响。
- 工作区已有内容视为用户资产，不覆盖、不回滚、不删除，除非用户明确授权。

## 目录约定

- 项目说明放在 `README.md`。
- 私密原始数据放在 `data/private/`，分析结果放在 `reports/private/`，均只保存在本机并由 `.gitignore` 排除。
- 可复用但不含私人原文的采集、整理脚本放在 `scripts/`。
- Skill 的工作副本放在 `skill/`；若需要自动发现，再安装到 Codex 个人 Skills 目录。
- 临时文件、缓存和生成物不得提交；新增后应同步补充忽略规则。
- 密钥、token、密码和个人敏感信息不得写入代码、日志或 Git。

## 数据边界

- 仅采集用户本人微信个人相册中当前账号可见的整条朋友圈：本人配文、图片或视频关键画面、转发卡片标题与来源、发布时间和公开/私密状态。
- 不采集好友信息流、点赞名单或私聊内容；评论默认不采集，只有在理解本人原帖语境确有必要时才记录用户本人的补充说明，不保留他人身份信息。
- 采集过程只读，不点赞、不评论、不转发、不发布，不修改微信隐私设置。
- 原始截图和媒体摘要只保存在 `data/private/`，用于图文关系与视觉偏好分析；完成后清理重复、无关和纯操作过程截图。
- 分析时严格区分“用户本人写了什么”和“用户选择分享了什么”，不得把转发标题或第三方文章写法冒充用户文风。
- 不把朋友圈原文、姓名、头像、位置或其他个人信息提交或推送到远端仓库。

## 验证规则

- 每次功能修改后执行与改动直接相关的最小验证。
- 能运行自动化测试时优先运行测试；不能运行时，说明原因和剩余风险。
- 对用户可见的页面、文档或文件，除代码检查外还要检查实际呈现效果。

## Git 规则

- 提交时只包含 `Deepself/` 内与当前任务相关的文件，不夹带仓库其他改动。
- 提交前检查暂存区，确保 `data/private/`、`reports/private/` 和其他个人素材未被跟踪。
- 禁止强制推送、重写历史或静默覆盖远端数据。
