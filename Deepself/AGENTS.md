# AGENTS.md

## 项目定位

- `Deepself` 是 `yao_1` 仓库下的独立子项目。
- 当前尚未确定具体功能、技术栈和运行方式；在需求明确前，不引入框架、依赖或样板代码。

## 工作规则

- 默认使用中文沟通，称呼用户为 Sir。
- 开始开发前，先明确项目目标、输入输出、使用场景和验收标准。
- 优先选择本地、简单、可维护的方案，避免无必要的复杂架构和依赖。
- 修改范围保持在 `Deepself/` 内；如需改动仓库其他目录，先说明原因和影响。
- 工作区已有内容视为用户资产，不覆盖、不回滚、不删除，除非用户明确授权。

## 目录约定

- 项目说明放在 `README.md`。
- 源代码、测试、文档、配置、数据和输出目录，待技术路线确定后再建立。
- 临时文件、缓存和生成物不得提交；新增后应同步补充忽略规则。
- 密钥、token、密码和个人敏感信息不得写入代码、日志或 Git。

## 验证规则

- 每次功能修改后执行与改动直接相关的最小验证。
- 能运行自动化测试时优先运行测试；不能运行时，说明原因和剩余风险。
- 对用户可见的页面、文档或文件，除代码检查外还要检查实际呈现效果。

## Git 规则

- 提交时只包含 `Deepself/` 内与当前任务相关的文件，不夹带仓库其他改动。
- 禁止强制推送、重写历史或静默覆盖远端数据。
