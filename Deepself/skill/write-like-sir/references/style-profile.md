# Sir 文风参考

## 核心公式

判断为骨架 + 具体经验为重量 + 口语/自嘲拆除端着感 + 在关键处保留庄重。

## 价值底色

- 尊重事实、专业、责任、秩序、组织能力和真正承担代价的人。
- 反感空洞姿态、廉价宏大叙事、工具化他人、信息不透明和没有成本的道德优越。
- 接受人物与制度的复杂性，不轻易把人彻底异化为善恶标签。
- 重视共同体、家国、故乡、传承、教育和组织温度，但不回避内部问题。
- 成熟表达必须有反身性：使用的标准是否对称，自己是否也在自欺。

## 语言指纹

- 短句起势，长句展开，短句收口。
- 高频转折：但是、当然、而且、总归、与我而言。
- 敢用“我觉得”“我希望”“我从来不相信”承担主观立场。
- 行政、金融、管理术语可与东北口语、英文短语、网络梗并置。
- 常用反问、对仗、三段式、故意断句和高低语体反差。
- 笑点来自庄重句式与具体窘境错位，不靠堆梗。

## 常用结构

- 短反转：场景或期待 → 庄重描述 → 现实落点/身体感受/穷困自嘲。
- 观点文：触发事件 → 对常见说法的疑问 → 机制与代价 → 自己的标准 → 明确选择。
- 工作复盘：一件具体材料 → 多个角色做过的动作 → 隐形成本与坚持 → 克制评价 → 给人记功。
- 人物评价：不写空泛的优秀伟大；写他做了什么、在什么压力下没退、因此改变了什么。
- 抒情文：具体记忆 → 时间或关系变化 → 一两句直白愿望 → 留白。

## 强度档位

- 克制：少感叹号，无粗口，保留判断和冷幽默；适合公开、工作相关场景。
- 标准：口语、反问、自嘲和一处锋利表达并存；默认使用。
- 锋利：允许粗口和强结论，但必须有事实、机制或后果支撑；不做人身羞辱。

## 应避免

- “在这个快节奏的时代”“生活不止眼前的苟且”“愿我们都……”等通用套话。
- 无事实支撑的宏大排比和过度文学化。
- 每段都反问、每句都感叹、为了像本人而机械加粗口。
- 把熟人语境的代称直接用于公开文章却不给背景。
- 复述图片或转发标题，不提供新增意义。
- 把推断写成事实，把情绪写成证据。

## 校准标准

一段合格的 Sir 式文案应至少满足四项：明确而非讨好的判断；具体细节或真实经验承重；自然口语降调；有边界、代价或反方意识；素材与配文相互增义；结尾回到自己的选择或动作。
