② 下载快捷指令 · v4

请在 iPhone 的 Safari 中操作。

  1. 先点“复制绑定码”，再下载 v4。在 Safari 下载项中打开「发送到办公电脑 L.shortcut」。
  2. 点“设置快捷指令”或“添加快捷指令”。出现“粘贴办公电脑 L 的绑定码”时，长按输入框 → 粘贴，然后完成添加。若提示同名，选择替换旧指令。若“添加快捷指令”没有反应，点底部“跳过设置”；回到快捷指令列表后，点这条指令的“…” → 最上面的“文本”框 → 粘贴绑定码 → 完成。
  3. 回到本页点下面的“检查配置”。看到“绑定信息已配置（v4）”后，从照片 App 分享一张照片给「发送到办公电脑 L」。首次发送按提示允许访问本站。
检查配置

绑定码保存在快捷指令本身，不再读写 iCloud 配置文件，也不用再点旧版的“自动绑定 L”。若跳过设置，直接在这条指令最上面的“文本”框里粘贴即可，无需添加操作。旧配置文件不用处理。

手动配置备用入口

仅在无法导入安装包时使用：新建同名快捷指令，在详情开启“在共享表单中显示”，接收“图像”“文件”和“媒体”。

  1. 添加“重复每一项”，输入选“快捷指令输入”。
  2. 在重复内添加第一个“获取 URL 内容”：使用下面的准备地址，方法选 POST；请求体选 JSON，添加“文本”字段，键名填 authorization，值粘贴下面的授权值。
  3. 紧接着添加第二个“获取 URL 内容”：地址选上一步的“URL 的内容”变量，方法选 POST；请求体选“表单”，添加类型为“文件”的字段，键名填 file，值选“重复项目”。它会把这一张照片送给 L。
  4. 在“结束重复”后添加“显示结果”，内容选“重复结果”。保存即可。

从照片 App 分享时，在“选项”中选“当前”以避免格式转换；指令里不添加“转换图像”或“调整大小”。大批照片运行时若提示限制，可在快捷指令的高级设置中允许共享大量数据。手机显示“已保存到 L”才代表电脑已保存；“等待保存”需到接收页确认。

此发送方式通过 HTTPS 把文件临时交给工具箱，再自动保存到 L。确认保存后清理临时副本，未完成的副本约 10 分钟后过期清理；不会写入 GitHub。授权值仅交给自己的手机。

首次设置后：照片 App → 选择照片 → 分享 →「发送到办公电脑 L」。日常发送无需先打开这个网页。

直接从相册多选，无需先导出。若系统弹出菜单，选“照片图库”；选图时若有格式或大小选项，选“当前”和“实际大小／原始大小”。每个文件最多 200 MiB，发送完成前保持页面打开。
