# 115 AI 文件整理系统 · 完整工作流设计

日期：2026-09-01

## 目标

在不下载视频、不删除文件、不覆盖同名文件的前提下，实现：扫描、索引、分类、重复风险识别、人工审核、操作清单、自动建目录、自动改名、自动移动和结果留痕。

## 工作流

```text
指定115子文件夹CID
  → 官方Open API只读扫描
  → SQLite索引与分类建议
  → HTML / Excel / JSON报告
  → 人工批准
  → 防篡改操作清单与APPLY确认码
  → 执行前再次核验
  → 建目录 / 改名 / 移动
  → 目标位置复核与操作日志
```

## 安全边界

- 不实现任何删除接口。
- 不使用文件名代替 115 原生 ID。
- 同一原生 ID 在列表中重复出现时只计一次，并单独统计重复返回次数。
- 只允许在指定扫描根目录内部创建 `已整理` 目录树。
- 低置信度、待识别和疑似重复项目默认不进入操作清单。
- 字幕、图片、压缩包和其他附件默认不进入自动清单，避免与对应主视频拆散。
- 清单必须来自本地已批准计划；清单被修改后确认码失效。
- 执行时再次核验来源文件 ID、父目录 ID、原文件名和当前批准状态。
- 目标同名时停止，不覆盖。
- 默认第一个错误立即停止，避免连续放大错误。
- 每次执行都写入本地操作日志，并在执行后重新扫描以刷新索引。

## 115 官方接口

- 列表：`GET /open/ufile/files`
- 新建目录：`POST /open/folder/add`
- 重命名：`POST /open/ufile/update`
- 移动：`POST /open/ufile/move`

实现参考 OpenListTeam 的 `115-sdk-go` 和 OpenList 115 Open 驱动。项目不实现 SDK 中的删除接口。
