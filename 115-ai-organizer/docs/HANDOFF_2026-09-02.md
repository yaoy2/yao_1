### 2.6 完整版实现

在只读扫描基础上补齐：

- 完整报告：HTML、Excel、JSON。
- 重复风险：SHA1 + 大小相同视为风险组，只报告、不删除。
- 当前快照：重扫后保留旧历史，但已删除或已移出的文件不会进入最新报告和操作清单。
- 安全批准：只自动批准高/中置信度、具有原生 ID、非重复、属于主视频类型的项目。
- 附件保护：字幕、图片、压缩包、“其他”和待识别内容默认不移动，避免与主视频拆散。
- 防篡改清单：任何手工修改都会令 `APPLY-` 确认码失效。
- 写入执行器：新建目录、重命名、移动；无删除接口。
- 冲突保护：目标存在同名文件时停止，不覆盖。
- 状态保护：来源 ID、父目录或名称变化时停止，要求重新扫描。
- 失败保护：默认遇到第一个错误立即停止并记录日志。
- 原生 ID 去重：115 列表重复返回同一 ID 时只计一次。

### 2.8 过程中出现的失败、绕路和修正

1. **OpenList 进程随命令结束**：早期从工具会话启动后，本地端口随会话退出，浏览器显示拒绝连接。后续改为使用 OpenList 自己的 `start` 方式，并以 `/ping` 返回 200 作为启动验收。
2. **只读账号路径重复**：只读账号的基本路径已经是 `/云下载`，程序再次请求 `/云下载` 时实际变成重复路径。已在 `app/openlist_client.py` 中增加逻辑路径到 API 路径的转换。
3. **空列表误判**：最初缓存空列表可能被当作探测完成。现已改为：空列表返回失败，并区分“刷新权限不足”和“确实为空”。
4. **OpenList 列表缺少原生 ID**：尝试通过 OpenList 公共列表读取 111 项成功，但字段中没有原生 `file_id`。没有继续用名称凑 ID，而是改用 115 官方 Open API。
5. **整根取消隐藏失败**：115 网页提示操作对象超过 5 万。最终放弃整根处理，改为按子文件夹 CID 分批取消隐藏和扫描。
6. **并发删减导致旧快照失效**：第一次完整递归时 Sir 同时在 115 删除文件。该轮得到 343 个目录、3103 个文件条目，约 839.8GB 扫描量；因为扫描期间远端发生变化，结果只视为旧历史，不用于执行。随后增加“只展示最新成功扫描快照”的规则，并在删减结束后重扫。
7. **Token 过期与 OpenList 停止**：重查文件夹时 115 返回 Access Token 无效，同时本地 OpenList 未监听 5244。重新启动 OpenList 后，它使用 Refresh Token 完成续期，再次读取成功。启动时还遇到一个失效 PID 记录，旧进程无法终止但并不存在；新进程成功启动，端口验收为 200。
8. **原生 ID 重复返回**：最新递归扫描遇到 1370 个文件条目，但只有 1342 个唯一原生 ID。现已把 28 次重复返回单独统计，并按原生 ID 只保留一份当前记录。
9. **测试夹具错误**：新增报告测试最初使用了非数字假 CID，Excel 测试也没有及时关闭只读工作簿，导致 3 项测试失败。修正测试数据和文件句柄后全部通过，没有通过跳过测试或屏蔽异常来绕过。
10. **调试输出风险**：早期一次 OpenList 调试运行在本地隐藏工具输出中显示过授权字段。调试立即停止并恢复普通模式；凭据没有写入源码、提交、报告或交接文档。后续 Token 已经历过期和自动续期。如果对该次本地调试输出仍有顾虑，可在新电脑开始真实写入前重新授权。

## 7. 已知限制与风险

1. 真实写接口尚未在 Sir 的 115 上执行过；单元测试通过不等于已经完成实盘验收。
2. 当前分类器主要依赖文件名和路径规则，不是影视数据库识别器，错误命名或信息不足会进入待识别。
