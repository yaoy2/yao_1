# 云下载整理与海报归档

遵循当前用户授权和 [项目集.md](../../../项目集.md)。这是独立的文件与海报流程。

## 1. 定位与完整清单

- 优先使用已有 Edge 登录会话；网页登录、OpenList 挂载、115 Open API 授权是独立状态。一个失效不代表另一个失效，不改挂载或凭据来绕过问题。
- 从当前页面确认云下载目录及其 CID。以文件 ID、实际父目录 ID 为操作对象，限定所有写入在已确认范围内。
- 保存原始清单：ID、父 ID、名称、类型、大小、SHA1 和目录路径。逐层覆盖分页；搜索结果只作加速，不能用含“.”的搜索证明所有文件夹或空目录已覆盖。
- 搜索结果中的 `p_id` 可能指搜索根目录；目录的实际父级以可见父目录链接或逐层读取结果为准。数量说明可能只统计当前已加载页：检查“加载全部”和下一页，不能因条目数与说明相等就认为完整。页面框架出现也不等于文件加载完成。
- 浏览器只用当前可用且有文档的操作工具；DOM 求值只读。大量行按不超过1000行分块读取，对比页面总数、实际行数和唯一 ID 数，防止工具截断或重复分页。
- 每完成一个目录就保存进度，单次批处理约30秒。失败从未完成项继续；超时后先看实际状态，不盲目重复改名、删除或上传。

## 2. 番号与改名

- 从实际视频名提取番号，合集逐片展开，去重排序后输出固定名 `番号.csv`，UTF-8 BOM，首列表头“番号”。保留未识别项和只有文件夹但无同番号视频的例外清单。
- 提取时排除网址数字、日期前缀、广告域名；保留真实厂牌编号及必要字母后缀，不能凭相似字符串把广告认成作品。不能把文件夹的番号自动当作它里面任意视频的番号。
- 改名前保存精确映射：ID、父 ID、原名、新名、大小、SHA1。只去除开头的网址/站点推广前缀，保留番号、分段、版本及扩展名。
- 在同父目录内检查大小写不敏感的重名，也检查计划内新名字互相冲突。必要时用 `（重名2）` 等明确标记保留两份；不覆盖、不自行去重删除。
- 优先使用115的批量重命名 CSV 导入及预览，固定表头为 `原名称,新名称,注：1、第一行固定不变、删除模板无效；`。同一原名对应不同新名时，按 ID 分批选择，使用执行时的名称制作映射。
- 只选实际要改名的 ID。115 可能为已选中的既有重名文件自动加 `(1)` 等序号，即使 CSV 留空、预览未显示变化；不能全选无关文件靠留空保护。确认预览与清单完全一致后应用，按 ID 验证新名、大小、SHA1、父目录及非目标项。
- 文件选择器等待不到事件时，检查可见入口；本次115的“电脑文件”可触发选择器，覆盖层中的 `input[type=file]` 未触发。单文件对话框若 DOM 操作超时，可用当前工具的可访问性界面操作。

## 3. 广告和空目录

- 删除须有本次或仍有效的明确授权。已授权的广告与空目录清理不重复询问。
- 依据名称、目录上下文等证据确认广告，不能只因体积小、扩展名或没有番号就删除。保护视频、字幕和真实资料；模糊项保留。
- 用已确认广告的 SHA1 识别换名夹带的相同内容，结合大小及上下文核实；空文件和极短通用说明不能仅因校验值相同就判为广告。
- 删除前复核选中 ID 与清单完全一致，使用正常回收站流程。只有整个子树都已核对为广告，才按目录整体删除。
- 搜索只用于缩小选择范围，最终选中集合必须与清单 ID 相等。较长或含特殊字符的组合查询可能返回空结果，不能据此判定文件已删除；以完整清单差异验收。
- 自下而上处理空目录，必须有完整加载且条目数为零的当前证据。保留删除清单，不清空回收站。

## 4. 非露骨海报与直接 Grok CLI

- 仅处理非露骨图片；不能代找或上传露骨色情图片。来源不合适或无法核实就明确记录，不继续委派该部分。
- 用户指定 Grok 时直接使用本机已登录的 `grok.exe`，不使用 `codex-grok-builder` 或其包装器。先检查本次登录与模型可用性，不改全局配置。
- 提供番号 CSV、成品目录、命名规则和逐项验收字段。不得把凭据、浏览器 cookie、私人清单中的无关字段交给检索任务。
- Windows 已验证的命令形态：无空格的绝对 Python 路径使用正斜杠，直接跟任务脚本路径；避免以 `&` 开头、内联脚本、命令链。使用本次进程的精确允许规则，先执行一个只读取 CSV 数量的无网络小检查。`dontAsk` 拒绝执行与 Grok 无法启动是两回事。
- 用独立会话 ID 和日志断点续做。检查实际工具结果、停止原因及输出文件，不能只看进程退出码。权限问题应查清具体规则，不开全局无条件批准。
- 先少量来源试查，再按已验证的来源结构批量处理。尊重登录、付费、验证码和访问限制；缓存、断点续做，避免无依据地遍历猜测地址。
- 每项记录番号、来源页、图片来源、来源编号、中文名、女优、文件名、尺寸、字节数、校验值、核实状态和未完成原因。不能凭网址中的番号、HTTP 200 或前三张图片就断言全部图片准确或不合适。
- 成品仅存 `E:\GoogleDrive\Ding2026\海报\云下载`；其他文件留任务工作目录。先完成核实，再执行已授权上传。

## 5. 同层归档与验收

- 上传位置取实际匹配视频的父目录。合集逐片映射；同一番号出现在多个目录时分别列目标。只有文件夹、没有匹配视频时不上传。
- 根目录无视频就无海报；不为单片文件夹额外复制根目录海报。
- 命名为“番号 中文名 女优.扩展名”，前部对应视频番号写法，以文件名排序验证相邻关系。原名、译名和女优有证据；不猜测信息，不把无关图片当封面。
- 按当前浏览器文件上传说明使用文件选择器。超时保留上传页，从独立清单页核对已落盘文件后，只补缺失项。
- 验收名称、实际目标父目录、字节数及可取得的SHA1，并检查原有非目标文件未改变。
- 最终简短报告CSV数量、实际改名/删除/上传数量、未完成项、成品位置。只有对应步骤真正验证通过才称为完成。
