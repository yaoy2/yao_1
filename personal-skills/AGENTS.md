# 个人 Skills 目录规则

## 目录结构

- 每个 Skill 使用一个独立目录，目录名与 `SKILL.md` 中的 `name` 完全一致。
- 每个 Skill 必须包含 `SKILL.md`；可按需包含 `agents/`、`scripts/`、`references/` 和 `assets/`。
- Skill 自身不放 README、更新日志、测试产物或临时文件；集合说明统一维护在本目录的 `README.md`。

## 内容要求

- 触发条件、适用范围、操作步骤、筛选标准、异常处理和完成报告必须写清楚。
- 不写入 Cookie、Token、密码、账号数据或机器专属隐私信息。
- 默认优先复用 Codex 已有能力和已登录浏览器状态，不无故新增依赖。
- 涉及下载、删除、发送或账号操作时，明确安全边界和失败后的处理方式。

## 发布与验证

- 修改 Skill 后，至少检查 YAML frontmatter、目录名、Skill 名、触发描述和引用路径是否一致。
- 若官方验证器可用则运行；缺少可选验证依赖时，不为此安装全局依赖，改做等价的结构检查并如实说明。
- 提交时只包含本次 Skill 及集合索引的相关变化，不夹带 Streamlit 代码、动态数据或本地生成文件。
