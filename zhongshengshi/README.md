# 众声室（已停用，留档说明）

> 状态：概念验证完成后于 2026-08-11 归档暂停；2026-10-05 随 M27 更名为「问山集 Wenshanji」（`wenshanji/`）删除全部源码。本目录只保留这份说明作为痕迹。

## 它曾经是什么

众声室是一个独立的 Next.js + TypeScript 本地多模型圆桌讨论 MVP，未并入 Streamlit 工具箱主程序。它想验证一种讨论方式：把同一个问题拆成立场不同的“席位”，再把席位分配给 DeepSeek、MiMo、Kimi 等模型，让它们以短消息形式接话、质疑、补充和反驳，而不是让单一模型生成一篇看似全面的长文。

归档前已实现：话题输入与 JSON 席位池解析、4 至 6 个席位的选择、每个模型最多承担两个席位的自动分配、服务端模型调用与不消耗额度的 mock provider、opening/debate 结构化流程与默认的 freechat 自由讨论、聊天气泡式 transcript、浏览器本地草稿恢复。归档时 27 项测试全部通过。

暂停原因不是程序不可用，而是应用价值不足：多模型自由讨论的调用和阅读成本，尚未证明比直接对一个模型多轮追问更有效。
