## 怎么打开

用浏览器打开同目录的 `apple_hub_preview.html`。

页面顶栏三个键：

- **预演**：白底、薄顶栏、大字、12px 缝的首页壳
- **现在**：当前暗色首页的对照
- **方案**：学什么、不学什么、下一步改哪些
