# 股票在线展示模块规则

## 模块定位

- 本目录只承载 YaoYao 工具箱中的股票在线展示能力。
- 页面入口固定为 `pages/18_19_stock_portal.py`，页面内包含“AStockLab”和“股票搜索”两个子板块。
- 本地生产项目仍位于 `E:\GoogleDrive\Ding2026\stock`；这里保存适合公开仓库和 Streamlit Cloud 的只读运行副本。

## 数据与安全

- 在线页面只读展示快照，不执行自动交易，不构成投资建议。
- 不提交 Cookie、token、账号信息、浏览器资料、日志、虚拟环境或临时文件。
- AStockLab 数据库以压缩快照提交，运行时解压到系统临时目录，不在仓库内生成 DuckDB、WAL 或锁文件。
- 股票搜索优先读取随仓库发布的公开信息快照；实时查询遇到登录、验证码、风控或站点限制必须明确标记不完整，不得绕过。

## 同步约定

- `astocklab/src`、配置、报告和数据库快照来源于本地 AStockLab。
- `search_html/collector.py` 与搜索数据来源于本地 SerchHTML。
- 同步后必须运行页面结构测试、搜索规则测试、压缩数据库完整性检查和相关 YaoYao 导航测试。
- 临时解压文件、测试缓存和同步辅助文件不得提交。

## 修改边界

- 在线兼容层放在本目录；不要为了上线而改变本地项目的数据保护和采集规则。
- 修改页面入口、数据格式或同步方式时，同时更新本目录 `README.md`。
