# 雪球 × 淘股吧 AI 股票舆情看板

## 在线展示

- YaoYao 工具箱中的线上入口为 `E:\github\yao_1\pages\18_19_stock_portal.py` 的“股票搜索”子板块。
- 线上版保存适合公开仓库的快照和搜索规则；本目录仍是本地采集、刷新和完整 HTML 服务的权威项目。
- 两端不会共享 Cookie、浏览器资料或账号信息。线上实时搜索受站点限制时会明确标记结果不完整。

## 使用

1. 双击 `双击这里启动看板` 快捷方式（带箭头的小图标）。
2. 浏览器会自动打开看板，不需要手工输入网址，也不需要安装文件编辑器。
3. 需要重新采集时，点击页面右上角“采集今日数据”。
4. 左侧打开“个股 / 关键词搜索”，输入股票名称、代码或关键词。程序会在提交时实时检索雪球、淘股吧公开全站搜索入口，只保留此前 7×24 小时内的帖子，并可切换“按热度 / 按时间”。
5. 关闭启动窗口即可停止本地服务。

本机的 `.bat` 文件关联曾被安全软件接管，因此本项目只使用上述快捷方式启动，不再把批处理文件作为正式入口。

`index.html` 是主页面。由于浏览器禁止普通 HTML 直接跨站读取雪球、淘股吧，自动采集必须由同目录的 `collector.py` 完成；页面本身不保存账号、Cookie 或密码。

实时搜索与右上角“采集今日数据”互相独立：搜索不依赖 `data/` 里的每日快照，热点、AI确认池和争议池仍使用每日快照。雪球公开搜索存在网页防护，因此搜索时会启动一个未登录的临时无界面浏览器会话；搜索完成即关闭，不读取用户浏览器资料。

## 结果解释

- 确认池：同一证券代码在两站均有中热以上证据，且至少一个 AI 子主题一致。
- 争议池：只有一站提及，或两站都提到但 AI 子主题不一致。
- 搜索未检出：当两站均显示“已完整翻至7天边界”时，代表两个公开搜索入口在该时间窗没有返回匹配帖子；若任一站显示“结果不完整”，则不能据此判断没有讨论。
- 搜索范围：从点击搜索的时刻向前精确计算 7×24 小时，并逐页检查发布时间。搜索结果不设热度门槛，热度只用于排序。
- 访问限制：若站点要求登录、出现验证码、触发风控或达到公开返回上限，程序立即停止该站并在页面说明，不绕过限制。

每日快照保存在 `data/YYYY-MM-DD.json`，最新结果同时写入 `data/latest.json`。
这些快照只服务热点与AI池，不再决定“个股 / 关键词搜索”的时间范围。
