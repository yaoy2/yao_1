# 网络备忘录设计规格

## 目标

新增一个 Streamlit 页面，用来快速保存网上看到的段子、金句、吐槽和可复用表达。页面文案使用“我来监督沙瑞金”。

## 页面命名

页面文件排在现有 Pages 之后，使用 `10_10、🧾_灵感便签盒.py`。这个名字延续现有“工具感 + 一点人格化”的风格。

## 核心功能

- 左侧快速记录：只显示输入框占位文字“请输入”，支持保存并自动打标签，也支持只保存。
- 右侧备忘列表：按日期倒序显示，每条记录用卡片呈现。
- 卡片颜色：读取 `data/color_palettes.md`，循环使用色卡方案。主色用于日期和左侧色条，辅助色用于装饰，背景色用于浅底。
- 分类标签：默认使用本地关键词规则生成分类和标签；后续可接入 LLM，但不作为首版依赖。
- 导出：支持一键导出全部记录为 Markdown；PDF 首版用浏览器打印友好的 HTML 文件承接，避免新增依赖。

## 数据

使用 SQLite 保存在 `data/web_memos.db`。每条记录包含日期、正文、分类、标签、色卡编号、创建时间、更新时间。

## 验证

为数据层新增测试，覆盖保存、倒序读取、关键词分类、Markdown 导出、色卡循环。
