# 技能协作优化：2026-09-05 评估，2026-09-06 发布记录

本记录保留本轮公开可复用的改动、测量口径和证据限制，不包含本机任务包、完整会话日志、账号信息或私密素材。评估发生于 9 月 5 日，发布文档与最终检查于 9 月 6 日整理；当前用法以各技能的 `SKILL.md` 和 README 为准。

## 本轮调整

| 范围 | 原有问题 | 调整后 |
| --- | --- | --- |
| GPT / Luna | 固定 Sol、网页规划和网页复审容易为简单任务增加交接。 | 模型未指定的小改直接完成；明确且执行量大的任务再委派；强模型处理关键不确定性，尊重明确模型、网页和只规划要求。 |
| Grok Builder | 主控可能先完成广泛探索，再把相同上下文交接，并反复盯执行。 | 目标、范围、验收明确后停止预读，不先写完整实现；合并任务包一次交接，执行者处理范围内探索、实现与普通修复。具体方案、范围和测试审批保留。 |
| Grok 包装脚本 | 日志名碰撞、stderr 混流、退出码不可靠，恢复标题可能成为不安全文件名；预演创建输出目录。 | 每次日志独立、stderr 单独保存、保留真实退出码；日志文件名改用独立 run ID，不再使用会话标题，`DryRun` 不创建目录或日志。 |
| 输出与费用记录 | 大量日志回流增加主控上下文；流程通过容易被误认为已经降本。 | `Quiet` 保存完整日志，只减少回流，不减少 Grok 自己的 token；从 CLI 终态读取实际用量和报价，缺失保持未知。 |
| PPT | 局部修改可能重复整套规划和检查。 | 复用已确认内容，检查受影响页面及相关全局约束，保留必要视觉验收。 |
| 小红书图片 | 已有可用登录时仍重复建立浏览器流程。 | 优先复用已登录、可控制的浏览器，保留放大判断与真人主体筛选。 |
| 存储分析 | 多种统计重复读取同一目录。 | 单次扫描缓存目录读取，保持输出和只读边界。 |

三项业务技能保存在 [personal-skills](../../personal-skills/README_ZH-CN.md)，不是新增独立运行项目。两项协作技能仍位于根目录。跨电脑使用时复制或安装到各自实际的 `CODEX_HOME/skills/`，不依赖固定盘符或 Junction。

## 独立通道实测

Luna 与 Grok 使用虚构 `merge_rows` 任务及同一组 12 项检查。网页测试只要求规划。时间按各自记录边界报告，不能直接横向排名。

| 项目 | 实际结果 | 时间边界 | 用量与费用 |
| --- | --- | --- | --- |
| Luna medium | 12/12，首轮通过，零修复 | 执行阶段约 22 秒 | usage 未提供，保持 unknown。 |
| Grok Build CLI | 12/12，首轮通过，零修复，5 轮 | CLI native 50.319 秒 | CLI 总量 96,927 token，其中 58,624 为缓存；CLI 回报 $0.01963398，非订阅账单。 |
| ChatGPT 网页，界面可见 6 Pro | 完成独立规划测试 | 规划约 94 秒 | 未获得可比较的 token 或费用数据。 |

这些数据不包含主控、准备和验收开销。网页规划与 Luna 执行是独立通道测试，没有运行完整的“网页规划 → Luna 执行”串行闭环；没有全程强模型基线。总 token、高价模型用量、订阅额度和实际费用是不同指标，不能从表中推出“已省 token”、节省百分比或费用排名。

## 检查结果与未实跑范围

- 存储缓存通过 5 项行为检查，8 组输出保持不变；虚构目录夹具的读取次数从 24 降到 14。只说明该夹具减少了重复目录访问，不代表真实磁盘扫描加速比例或模型成本。
- Grok 包装脚本通过 11 次模拟运行、16 项断言，包括退出码 7、独立日志、`Quiet`、缺失或损坏终态、仅取最后一个终态而不累计。`run.json` 提供 `TokenUsage`、`NumTurns`、`ResolvedModels`、`CliReportedCostUsd` 和 `UsageStatus`；未提供的字段保留 `null`，`ActualSubscriptionCharge` 为 `unknown`。
- M22 页面检查为 4 项测试、19 项子检查通过。主应用在仓库已有环境中运行 `python -X utf8 -B -m pytest -q tests -p no:cacheprovider`，174 项测试、19 项子检查通过，耗时 6.81 秒。首次用系统 Python 时因缺少 `slugify` 无法收集微信模块测试；改用已有项目环境后通过，未安装依赖。
- 本轮未执行实际全盘扫描、真实 PPT 制作或修改、小红书业务采集。业务技能的流程调整仍需在以后真实任务中按范围验收，不将规则变更写成业务实跑成功。
