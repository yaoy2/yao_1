# M20 校历与学期归档规则

更新日期：2026-11-02。本文件为项目规则，供 M20 纪要、考勤分发及后续维护共同遵守。

## 会议纪要范围

- 系部例会纪要仍覆盖医学信息工程系、医学影像系、健康服务与管理系和健康体育部。
- 用户同日要求增加学院党政联席会**统一命名的 PDF**，并入界面的“会议纪要”选项；统一文件名形如 `健康学院党政联席会会议纪要-健康学院2026-2027学年第一学期教学第七周.pdf`，兼容末尾的 ` (1)` 等下载副本标记。
- 目标为 `02_学期工作/材料所属学期/03_会议_考勤/党政联席会_系部例会/党政联席会`，沿用现有目录，保留原文件名；同内容重复或同名冲突仍按现有分发规则处理。
- 此次只扩展学院党政联席会 PDF，不扩展到其 Word 稿、考勤表、发言稿、封皮、党总支委员会、校党委或其他会议。标准文件名与正文题头或校历时间冲突时待核对，不能单凭名称忽略冲突。

## 依据与归档边界

- 依据用户提供的《成都东软学院2026-2027年度第1学期校历》，原件位于 Ding2026 根目录。已核对单页校历的周次、日期和备注，原件保持只读，不进入公开代码仓库。
- 用户明确规定：**2026年9月14日至2027年1月15日，首尾均含，归入 `2026-2027-1` 学期**。
- 周次以学校校历为准，按周一至周日核对；国庆、中秋、元旦等节假日不改变周次顺序。不采用自然年的 ISO 周数。
- 校历注明行课16周，期末考试时间为2027年1月4日至8日；表中考试周整行为1月4日至10日，总结周整行为1月11日至17日。**本项目归档范围按用户要求截止1月15日，不延伸至1月16、17日。**

## 判断顺序与冲突处理

1. 保留并核对文件名、正文标题和明确的学年、学期、会议日期、考勤日期、时间、周次字段。讨论内容、未来安排、附件提及的日期不作为材料所属时间；文件下载、创建、修改时间和系统当前时间均不作为依据。
2. 完整日期能落入上述范围时，可据校历确定 `2026-2027-1`，并在预览中显示对应周次。例如2026年10月20日对应第6周，2026年10月28日对应第7周。
3. 只有月日或“第几周”，没有完整年份、学期时，使用**用户已确认、界面明确显示的本批校历**补全；当前默认是 `2026-2027-1`。例如“第七周考勤”按本批校历对应10月26日至11月1日；“9月22日会议纪要”对应2026年9月22日、第2周。该行为不是从“今天”猜学期。
4. 处理混合学期或历史材料时，可以取消界面上的“仅有周次或月日时，按本批校历补全学期”。取消后，单独的周次或月日不能确定学期；明确完整日期或完整学期仍可使用。
5. 已明确其他学期的材料保留原学期，不因为本批校历设置就改入本学期；若其实际日期落入本学期，与注明学期冲突，则保留待核对。未提供其他学期校历时，不声称已核对其他学期的周次。
6. 日期与注明周次不一致，或文件名和正文题头周次不一致时，提示冲突和校历对应周次；不改原文件名、不强行分发。例：“第7周”但日期是2026年10月20日，应提示日期对应第6周。
   用户对具体文件确认正文周次为笔误后，可按其指定且与校历日期一致的周次分发；不修改正文和文件名，并在本机分发记录中保留确认依据。2026-11-02，用户已确认日期为9月21日、文件名为“第二周”而正文写“第一周”的学院党政联席会PDF按第2周归档。该确认不自动扩展到其他冲突文件。
7. 跨周考勤须注明清楚的周次范围，日期应落在该范围内。无效日期、范围外日期、无法确定的学期继续待核对。

## 分发后的统一命名

- 系部纪要：`单位正式名称-会议纪要-第x周`；考勤：`考勤表-单位正式名称-第x周`。接原扩展名，保留大小写和文件内容；党政联席会纪要保持原文件名。
- 普通周次转为阿拉伯数字，单位使用已核对的正式名称。跨周保留完整范围；考试周、总结周保持校历名称。周次不明确或冲突时留待核对，不以文件创建日期代替。
- 预览列出原文件名和分发后的文件名，确认分发时直接保存为最终名称。只有本次勾选的文件参与；历史归档不批量改名。同批不同内容会产生同名时全部待核对，同名不覆盖。

## 当前程序能力与维护要求

- 四项分发规则独立选择；只有勾选会议纪要、考勤时才处理相应材料。执行前复核与预览时使用相同的本批校历，记录所用学期及结果。
- 目前可读取 DOCX、XLSX 和 PDF 文字层。旧 DOC/XLS 和没有文字层的扫描 PDF 若文件名已有明确日期、周次或学期，可使用这些可见线索；程序不把“按文件名核对”写成“已读取正文”。线索不足时保留待核对，不要求为了分发而改动原件。
- 校历数据维护在 `integrations/file_distribution/school_calendar.py`，识别使用 `weekly.py`。GUI、预览报告、执行记录、说明和本文件的日期、周次口径必须一致。
- 新学期需取得对应校历或用户确认后再更新上下文，不按当前时间自动切换学期。
- 验证应覆盖起止边界、节假日、跨年、考试周/总结周、日期与周次冲突、取消上下文以及执行前复核。真实材料只读验收；移动测试用隔离样本。
