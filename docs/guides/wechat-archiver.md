# 微信公众号与本地文件归档指南

[返回文档导航](../README.md)

这是运行在本机浏览器中的 Streamlit 归档页面。根目录的 `启动微信归档窗口.bat` 会打开 [localhost:8502](http://localhost:8502)，主工具箱默认使用 8501。页面支持公众号文章抓取、本地文件复制，以及学院资料的路线识别。

## 打开与使用

1. 首次使用时，在仓库根目录双击 [`首次安装.bat`](../../首次安装.bat)，建立项目虚拟环境并安装依赖。已有可用环境时不必重复安装。
2. 双击 [`启动微信归档窗口.bat`](../../启动微信归档窗口.bat)。若浏览器未自动打开，访问上面的本机地址；运行期间保留启动窗口。
3. 在输入区粘贴公众号链接或完整本地文件路径，并写明归档目标。
4. 核对页面“识别结果”和“本地目录”。没有写明目标时，页面按右侧选择的“课题”或“竞赛”处理，初始默认是课题。
5. 点击“开始归档”才会执行支持的路线；完成后核对结果中的保存路径、成功数和失败数。

## 四条路线

| 路线 | 输入方式 | 当前页面执行内容 |
|---|---|---|
| A：公众号 → raw | `归档raw` + 公众号链接 | 抓取文章，保存 Markdown 和配图到 raw 目录。 |
| B：公众号 → 课题／竞赛 | `归档课题` 或 `归档竞赛` + 公众号链接 | 抓取文章，保存 Markdown 和配图到对应目录。 |
| C：本地文件 → 学院 | `归档学院` + 本地文件路径 | 只识别并提示；上传到 IMA“健康学院-2026”需另由 WorkBuddy 执行。 |
| D：本地文件 → 课题／竞赛 | `归档课题` 或 `归档竞赛` + 本地文件路径 | 复制文件到对应目录，保留原文件；遇到同名文件会另取文件名。 |

本窗口不会自动上传到 IMA。路线 B、D 如还需要 IMA 留存，也需另行执行上传。

公众号输入示例：

```text
归档竞赛
https://mp.weixin.qq.com/s/xxxx
https://mp.weixin.qq.com/s/yyyy
```

本地文件输入示例，路径有空格时保留双引号：

```text
归档课题 "E:\材料\课题申报通知.pdf"
```

## 浏览器与常见问题

- 公众号抓取通过 Playwright 调用电脑上的 Microsoft Edge；该流程不需要另装 Playwright Chromium。
- 遇到验证码或微信风控时，可取消勾选“后台运行浏览器”，观察 Edge 中的提示。
- 本机地址打不开：先查看启动窗口的报错，确认 `.venv` 已安装、8502 没有被其他程序占用。
- 本地文件无法识别：检查是否使用完整路径，并核对页面识别出的文件数量。
- 显示学院路线需要 WorkBuddy：这是当前能力边界，页面不会自行完成 IMA 上传。
- 结果显示部分失败：按每项错误判断是抓取、文件读取还是保存问题，不把“处理结束”当作全部成功。
