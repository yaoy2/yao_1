# 首页视觉预演（历史设计稿）

[返回文档导航](../README.md)

这里保留学院行政智能中枢首页的 Apple.com.cn 风格预演，用于回看设计过程和跨电脑继续讨论。它最初是未实施方案；正式首页后来已采用浅色主题并继续迭代为分区导航，因此旧说明中的“尚未实施”和“现在的暗色首页”已不能代表当前版本。

当前首页以 [`hello.py`](../../hello.py)、[`utils/home_theme.py`](../../utils/home_theme.py) 和 [`utils/home_theme.css`](../../utils/home_theme.css) 为准。保留这份预演不表示现有页面与历史稿逐像素一致。

## 怎么打开

用浏览器直接打开同目录的 [`apple_hub_preview.html`](apple_hub_preview.html)，不需要启动 Streamlit 服务。

页面顶栏三个键保留了当时的对照：

- **预演**：当时拟议的白底、薄顶栏、大字和首页间距。
- **现在**：当时的暗色首页示意，不是当前线上页面。
- **方案**：当时对取舍和下一步的讨论，不是待自动执行的任务清单。

## 保留约定

- 本目录只放可独立打开的静态设计稿与说明，不放正式页面源码、真实业务数据或浏览器运行缓存。
- 当前 HTML 保持原稿，页面中的模块、文案和状态可能早于当前产品。
- 后续若采用其中的设计，先说明要改的范围和效果，再按项目规则实施；不要直接覆盖当前首页。
